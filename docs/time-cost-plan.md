## 7. Earned Value за Sprint 1
 
| Метрика | Розрахунок | Значення | Джерело в Jira |
|---------|-----------|---------:|----------------|
| PV | Заплановані SP × вартість SP | $663.78 | Sprint Report → Committed |
| EV | Завершені SP × вартість SP | $663.78 | Sprint Report → Completed |
| AC | Σ Time Spent × $15 | $600.00 | Time Tracking Report |
| **CV** | EV − AC | $63.78 | |
| **SV** | EV − PV | 0.00 | |
| **CPI** | EV ÷ AC | 1.11 | |
| **SPI** | EV ÷ PV | 1.00 | |
| **EAC** | Total Budget ÷ CPI | $2,735.14 | |
